# Gitfy

Aplicação web desenvolvida com **React 19**, **TypeScript** e **Vite**, utilizando **HeroUI** e **Tailwind CSS**.

## 🚀 Tecnologias

- **React 19**
- **TypeScript**
- **Vite**
- **Tailwind CSS v4**
- **HeroUI**
- **Zustand**
- **Axios**
- **ESLint & Prettier**

## 🛠️ Como Executar

### 1. Instalar as dependências

```bash
npm install
```

### 2. Rodar o projeto em ambiente de desenvolvimento

```bash
npm run dev
```

### 3. Outros Scripts

- **Build de produção:**
  ```bash
  npm run build
  ```
- **Preview do build:**
  ```bash
  npm run preview
  ```
- **Linting:**
  ```bash
  npm run lint
  ```
- **Correção de Lint & Format:**
  ```bash
  npm run lint:fix
  ```
